# Sesión: base local de recuperación

Fecha: 2026-10-15. Contexto: inicialización del repositorio `iromem` según `.creation/` y el alcance corregido del MVP.

Se creó workspace Rust, registro explícito de `retrieval`, migración SQLite mínima, loader de fixtures y búsqueda FTS5 con filtro de ámbito/revisión/estado/tiempo. Se mantuvo el README del diseño propuesto y sus anexos; `origin` apunta a la URL SSH dada por el usuario, sin commit ni push. No se usaron datos reales ni la caché de Laya para inferencia.

Verificación de esta sesión: `cargo test --offline --workspace` pasó con once pruebas después de descargar artefactos transitivos faltantes; un ensayo CLI temporal cargó dos memorias sintéticas y recuperó solo la del ámbito solicitado. Se añadió un banco sintético de 10.800 consultas y pilotos separados, una composición parcial de semilla validada contra ID/revisión autorizados y un índice semántico versionado con coseno exacto/RRF probado en 270 consultas de desarrollo. La clave opcional de OpenRouter se lee bajo `IROMEM_OPENROUTER_API_KEY` y no se imprimió su valor al migrar el `.env` local. Esta evidencia corresponde a la base actual de la fecha, no a versiones futuras. Pendientes: perfil de embedding independiente, pipeline integrado de clasificación/semilla y campaña comparativa final. No hay hook ni MCP.
