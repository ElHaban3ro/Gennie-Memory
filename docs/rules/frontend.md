# Interfaz de usuario retirada

El usuario pidió eliminar el dashboard el 2026-10-23. Se retiraron React/Vite, servidor HTTP, comando dashboard y reutilización del feedback en recall/session. Actualmente el producto usa CLI/JSONL sin puertos.

No se exige build npm ni se debe recrear la UI para completar el contrato v1. Una interfaz futura requerirá alcance y reglas actualizados. La [decisión original](../decisions/0014-local-review-dashboard.md) es histórica; la [retirada](../decisions/0047-remove-dashboard.md) define el estado vigente.
