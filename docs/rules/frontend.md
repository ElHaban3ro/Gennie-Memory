# Dashboard local

`apps/dashboard/web/` contiene el cliente React 19 + Vite 8 con TypeScript. `apps/dashboard/src/` posee las rutas HTTP, la revisión y sus tablas; `bootstrap` registra el módulo y arranca el servidor bajo la misma conexión SQLite del proceso. El dashboard escucha en `127.0.0.1` por defecto; una IP privada explícita habilita el acceso directo desde la LAN. La UI no llama directamente a SQLite ni a OpenRouter.

La primera pantalla es una mesa de revisión: lista de preguntas, pregunta activa, recuerdos candidatos con ID/revisión/fuente y una decisión explícita por recuerdo. Al abrir una pregunta, la revisión rápida presenta primero cinco resultados de búsqueda y permite ampliar de cinco en cinco; la lista completa del ámbito es una vista explícita. El usuario puede confirmar varios recuerdos sin clasificar los demás: los no marcados no se consideran negativos explícitos. «Ninguno responde» solo se puede guardar después de mostrar todos los resultados de la vista de búsqueda; «falta un recuerdo» es un estado distinto. La revisión rápida es feedback de producto, no una auditoría ciega exhaustiva. La vista mantiene visible la pregunta y un criterio neutral: el orden automático no constituye una etiqueta correcta. En casos sintéticos solo se juzga pertinencia de los resúmenes; no se verifica el texto fuente de la conversación. La vista no muestra etiquetas esperadas de los fixtures. Al abrir un caso de la cola oculta también las referencias de fuente, que pueden codificar categorías de respuesta. Los textos son del usuario y se insertan en React como texto, nunca como HTML. El cliente confirma en la respuesta del servidor lo que se guardó, muestra errores recuperables y protege las ediciones pendientes al cambiar de pregunta o de vista.

Dirección visual: superficie gris azulada, tinta azul profundo, acento verde petróleo y ámbar para incertidumbre. Tipografía del sistema, cifras e IDs monoespaciados; sin fuentes ni CDN. La jerarquía prioriza leer evidencia y tomar una decisión, no indicadores decorativos. Pantalla amplia con cola lateral y área de revisión; en móvil, cola plegada y tarjetas apiladas. Controles con etiquetas, foco visible, contraste suficiente y soporte de movimiento reducido.

La compilación Vite produce `apps/dashboard/web/dist/`, ignorado por Git; el binario Rust sirve esos archivos. `npm run build` y `npm run typecheck` verifican el cliente. Para desarrollo, Vite redirige `/api` al servidor local y permanece en loopback. El cliente abre la misma URL simple en el navegador integrado y en Safari. No hay cuentas ni separación de usuarios en esta primera versión; quien alcance el puerto en la LAN puede consultar y guardar revisiones. El consentimiento para compartir datos es explícito por exportación revisada; ninguna acción de la UI envía datos fuera del equipo.
