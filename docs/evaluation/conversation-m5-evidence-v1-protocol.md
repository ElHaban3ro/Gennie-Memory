# M5: variante experimental de selección por evidencia

> Corrección de cierre, 2026-10-17: se conservan el protocolo, los datos y las puntuaciones históricas. Las selecciones discordantes con una etiqueta negativa no prueban una afirmación falsa; algunas preservan evidencia que refuta la pregunta. Las conclusiones de mejora de verdad o superioridad derivadas solo de esa abstención quedan retiradas. Véase el [cierre de M5](m5-closeout-2026-10-17.md).

Estado: definida antes de llamar al proveedor con esta variante, 2026-10-17. Se usa solo `conversation-m5-v2-development` (100 casos agente-sintéticos) para diagnóstico emparejado. No se modifica el buscador, el modelo ni la ruta predeterminada. Calibración, reserva y muestra humana permanecen cerradas.

`RecallRequest.selection_policy` admite `baseline` (por defecto) y `evidence_v1` explícito. El cambio único de inferencia es el texto de `questions.relevance.instructions` del mismo endpoint Decisions. `evidence_v1` pide comprobar que el recuerdo afirme el hecho solicitado, incluido su momento y estado de terminación o autorización; una propuesta, solicitud, plan, prueba, estimación preliminar o comparación no confirma un resultado final, aprobado, completado o adjudicado. Si ningún recuerdo lo afirma, se selecciona `none`. El texto exacto está fijado como `EVIDENCE_V1_INSTRUCTIONS` en `bootstrap/src/openrouter.rs`; no se reescribe durante la campaña. No se proporciona al clasificador la etiqueta, el ID esperado, el segmento ni el resultado previo. La pregunta y los candidatos se conservan.

Primero se comprueba el contrato local y la igualdad de candidatos con la campaña base. Después, un piloto de hasta 100 llamadas Decisions en la misma SQLite temporal y los mismos casos registra un diario con hashes del banco, binario y DB, política, respuestas, latencia y coste informado. Se compara por ID de caso: positivos correctos, negativos vacíos, falsos recuerdos, degradación, cruces de ámbito y tiempos p50/p95. El fallo de transporte previo cuenta como fallo de campaña de referencia y se separa de los fallos de selección; no se reintenta aquella llamada incierta. Un nuevo fallo de transporte también se conserva como tal.

La variante se descarta si introduce un falso recuerdo nuevo, pierde un positivo antes correcto o no corrige los tres negativos problemáticos. Aunque cumpla ese criterio en desarrollo, no se promueve al predeterminado: los tres errores fueron observados antes de diseñarla. Solo una variante que lo cumpla pasa a una comparación previamente fijada en conversaciones nuevas de calibración. La instrucción más larga puede elevar tokens, coste o latencia; esas cifras se informan. Ninguna cifra de este banco representa comportamiento poblacional ni revisión humana.
