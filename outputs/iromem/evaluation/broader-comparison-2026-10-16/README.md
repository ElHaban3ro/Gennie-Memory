# Frozen external-engine evidence

This directory contains four 540-case retrieval runs each for Basic Memory and fully embedded Lodis, plus two valid six-case Codex rounds for each. The cases and order files are frozen in `../full-comparison-2026-10-16/`; the original iROMEM and Engram results remain there. Each search manifest records case, mapping, and binary hashes. Search summaries were produced by the Rust `iromem-eval retrieval` command. The Lodis map reports 2,800 persisted embeddings.

`search-basic-memory-N.jsonl` and `search-lodis-semantic-N.jsonl` are per-case results. Each corresponding `-summary.json` includes accuracy and latency. `codex-{lodis,basic-memory}-valid-{1,2}/summary.json` and the case event logs contain completed MCP calls and answers. `codex-lodis-1/` is an invalid initial attempt blocked by tool approval; `diagnostic-lodis-no-embeddings/` is an invalid first import with lexical fallback; `diagnostic-basic-memory-*` records incomplete MCP startup attempts. None enters the reported numbers.

The external checkouts and isolated stores were created under `/private/tmp/iromem-{basic-memory,lodis}-eval-20261016`. These paths are machine-local and are **not** included in this package. Reproduction requires the pinned upstream revisions and dependencies described in [the report](../../../../docs/evaluation/broader-comparison-2026-10-16.md). No credentials are stored here. Local searches incurred no paid model calls; the reported historical Decisions and Jev cost is in the original comparison.
